## 🔬 Project Overview

An **AI-driven medical imaging system** designed to detect brain tumors from **MRI and CT scan images** using a **Convolutional Neural Network (CNN)**. The system integrates **machine learning, computer vision, and embedded hardware** to provide **real-time diagnostic indicators using Arduino-controlled components**.

> 🏥 This project demonstrates how **Artificial Intelligence and IoT-based hardware** can be combined to build intelligent, accessible healthcare assistance tools.

Brain tumor diagnosis typically requires expert radiologists to analyze scans — a process that can be **time-consuming, expensive, and dependent on specialist availability**. This system proposes an **AI-assisted alternative** that works in three layers:

<br/>

<div align="center">

| 🟢 Detection | 🌐 Interface | 🔌 Hardware |
|:---:|:---:|:---:|
| CNN classifies scans as **Healthy** or **Tumor Detected** | Results shown live on a **Streamlit Web App** | **Arduino** drives LEDs, LCD & Servo indicators |

</div>

## 🧠 Machine Learning Model

The system uses a **CNN** trained on brain scan datasets with **~96% classification accuracy**.

<br/>

<details>
<summary><strong>📐 Model Architecture &nbsp;—&nbsp; click to expand</strong></summary>

<br/>

```
Input Image (128 × 128 Grayscale)
        │
        ▼
┌───────────────────────────┐
│  Conv2D Layer (32 Filters) │
└──────────────┬────────────┘
               ▼
┌───────────────────────────┐
│     MaxPooling Layer       │
└──────────────┬────────────┘
               ▼
┌───────────────────────────┐
│  Conv2D Layer (64 Filters) │
└──────────────┬────────────┘
               ▼
┌───────────────────────────┐
│     MaxPooling Layer       │
└──────────────┬────────────┘
               ▼
┌───────────────────────────┐
│       Flatten Layer        │
└──────────────┬────────────┘
               ▼
┌───────────────────────────┐
│  Dense Layer (128 Neurons) │
└──────────────┬────────────┘
               ▼
┌───────────────────────────┐
│       Dropout Layer        │
└──────────────┬────────────┘
               ▼
┌───────────────────────────┐
│   Softmax Output Layer     │
│  [Healthy]  [Tumor]        │
└───────────────────────────┘
```

</details>

<details>
<summary><strong>🖼️ Image Preprocessing Pipeline &nbsp;—&nbsp; click to expand</strong></summary>

<br/>

| Step | Operation | Detail |
|:---:|:---|:---|
| 1 | Grayscale Conversion | RGB → single-channel image |
| 2 | Resize | Normalize dimensions to **128 × 128 px** |
| 3 | Pixel Normalization | Scale values to `[0, 1]` range |

</details>

## ⚙️ Project Workflow

<br/>

```
  📤 User Uploads MRI / CT Image
             │
             ▼
  🖼️  Image Preprocessing
      Grayscale → Resize (128×128) → Normalize
             │
             ▼
  🤖  CNN Model Prediction
      TensorFlow / Keras Inference
             │
             ▼
  🌐  Result on Streamlit Web Interface
      Confidence Score + Visual Output
             │
             ▼
  🔗  Serial Communication → Arduino (PySerial)
             │
             ▼
  💡  Hardware Indicators Activated
      LED  ·  LCD Display  ·  Servo Motor
```
